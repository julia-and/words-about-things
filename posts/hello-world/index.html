hello, world

2026 · 05 · 11 · #meta

A new site, built with Zola: a single Rust binary that takes Markdown and templates and gives back a folder of HTML. Zero JavaScript ships to your browser. Zero cookies are set. Syntax highlighting happens at build time — what you’re about to see is just <span> tags and CSS.

why bother

I like the small web. Pages that load instantly, work without consent banners, and don’t watch you back. This place is a notebook for code, longer-form thinking, and the occasional log entry.

a snippet, because we have to test it

Some Rust:

fn main() {
    let rose = "🌹";
    let greeting = format!("hello from {rose}");
    println!("{greeting}");
}

And a shell incantation:

# build, then push
zola build && rsync -avz public/ host:/var/www/blog/

A bit of TOML for good measure:

[markdown]
highlight_code = true
highlight_theme = "css"

hidden things

There are easter eggs. None of them need JavaScript. Try:

  • View Source on this page.
  • Hover the period at the end of the bio on the homepage.
  • Look in /humans.txt and /robots.txt.
  • Visit a URL that doesn’t exist.
