{#- gradient_select(text, startColor, endColor) Renders `text` so that the ::selection (highlight) colour of each character steps along a gradient from startColor to endColor, inclusive. The number of gradient steps equals the number of characters in `text`. Colours are hex, either #rgb or #rrggbb (the leading # is optional). Each call is scoped to the page + shortcode index, so it is safe to use the shortcode many times on one page. -#} {%- set sc = startColor | replace(from="#", to="") | lower -%} {%- set ec = endColor | [sc, ec] -%} {%- set_global CA = [] -%} {%- set colsrc = col | split(pat="") -%} {%- for c in colsrc -%}{%- if c != "" -%}{%- set_global CA = CA | concat(with=c) -%}{%- endif -%}{%- endfor -%} {%- set short = CA | length == 3 -%} {%- set_global COMP = [] -%} {%- for j in range(end=3) -%} {%- set jhi = j * 2 -%}{%- set jlo = j * 2 + 1 -%} {%- if short -%}{%- set hi = CA[j] -%}{%- set lo = CA[j] -%}{%- else -%}{%- set hi = CA[jhi] -%}{%- set lo = CA[jlo] -%}{%- endif -%} {%- set_global hv = 0 -%}{%- set_global lv = 0 -%} {%- for k in range(end=16) -%}{%- if HEX[k] == hi -%}{%- set_global hv =
